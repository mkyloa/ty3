# Пастки EN→UK у субтитрах

Ці конструкції зустрічаються в майже кожному фільмі, і саме на них машинний
переклад видає себе. Ліва колонка — англійський оригінал, права — природні
українські варіанти. Вибирай за контекстом і реєстром персонажа, а не перший.

## Дискурсивні маркери (найчастіша причина «перекладності»)

| Оригінал | Природно | Калька, якої не треба |
|---|---|---|
| `Look,` / `Look at me` | `Слухай,` / `Ось що` | `Дивись,` (коли ніхто нікуди не дивиться) |
| `I mean,` | `Тобто` / `Та ні` / `У сенсі` | `Я маю на увазі` (задовго для субтитра) |
| `You know what?` | `Знаєш що?` / `Отак от` | `Ти знаєш що?` |
| `You know,` | `Розумієш,` / (часто просто прибрати) | `Ти знаєш,` |
| `Well,` | `Ну` / `Гаразд` / (прибрати) | `Добре,` |
| `Come on!` | `Ой, перестань` / `Та ну` / `Ходімо` (за контекстом!) | `Давай!` |
| `Right.` | `Ага` / `Ясно` / `Отож` | `Правильно.` |
| `Fine.` | `Гаразд` / `Ну добре` / `Як хочеш` | `Прекрасно.` |
| `Okay.` | `Гаразд` / `Добре` / `Ясно` | `Окей` (лише як риса персонажа) |
| `Anyway,` | `Так чи так,` / `Коротше,` | `У будь-якому разі,` (задовго) |
| `Actually,` | `Насправді` / `Узагалі-то` | `Актуально` |
| `Sure.` | `Аякже` / `Певно` / `Давай` | `Звичайно.` (не завжди) |
| `Whatever.` | `Та байдуже` / `Як хочеш` | `Що завгодно.` |
| `Seriously?` | `Ти серйозно?` / `Це жарт?` | `Серйозно?` (буквально, але млявo) |
| `Oh, my God!` | `О Боже!` / `Господи!` / `Матінко!` | `О, мій Боже!` |
| `Jesus!` (вигук) | `Господи!` / `Боже` / `Трясця!` | `Ісус!` |
| `Excuse me?` (обурення) | `Що, прошу?` / `Перепрошую?` | `Вибачте мене?` |

| Оригінал | Природно |
|---|---|

| `Ma'am` | `пані` / `мадам` |
| `Mr. Smith` | `пан Сміт`, у звертанні — `пане Сміт` |
| `Mrs. / Ms. Hollis` | `пані Голліс` |
| `Doctor` (звертання) | `лікарю` (кличний!) / `докторе` |
| `Officer` | `офіцере` / `пане полісмене` |
| `Honey` / `Sweetheart` | `милий` / `мила` / `сонечко` / `любий` (рід!) |
| `Buddy` / `Man` | `друже` / `чоловіче` / `слухай` |

## Конструкції, що потребують перебудови

| Оригінал | Природно | Чому |
|---|---|---|
| `I need you to leave.` | `Тобі треба піти.` | буквальне `Мені потрібно, щоб ти` — задовго |
| `I want you to know...` | `Знай, що…` | те саме |
| `There's something I have to tell you.` | `Маю тобі щось сказати.` | економія символів |
| `It's not what you think.` | `Це не те, що ти думаєш.` | ок буквально |
| `I don't have time for this.` | `Мені не до цього.` | коротше і природніше |
| `Make sure you...` | `Обов'язково…` / `Гляди,…` | |
| `I'll be right back.` | `Я зараз.` | |
| `Do you mind if I...?` | `Можна, я…?` | |
| `It doesn't matter.` | `Це не має значення.` / `Байдуже.` | не `не грає ролі` |
| `As soon as possible` | `Щонайшвидше` | не `як можна скоріше` |

## Пастки роду й числа

- `You were right` — рід адресата: `мав рацію` / `мала рацію` / `мали рацію` (Ви).
- `I'm ready` — рід мовця: `готовий` / `готова`.
- `They` про одну особу невідомої статі — перебудуй без роду.
- `We` — уточни, чи включає адресата: іноді краще `ми з тобою`, іноді `я з ними`.

## Технічні дрібниці, які помічають

- Обірвана репліка: англійська ставить `--`, українська — тире `—` або трикрапку `…`.
- `Uh` / `Um` / `Er` — у субтитрах зазвичай **прибирають**, вони чутні й так.
- Повтори затинання (`I-I-I don't know`) — передавай, лише якщо це риса персонажа.
- Написи на екрані (`forced`) — капслок джерела зберігай капслоком.
- SDH-опис звуку (`[DOOR CREAKS]`) перекладай і лишай у дужках: `[ДВЕРІ СКРИПЛЯТЬ]`.
